## Methodology Adopted From Papers

- From SREGym:
  - Live environment instead of static Q&A.
  - Faults rather than symptoms.
  - Multi-layer root causes across Kubernetes, GPU scheduling, storage, network, controllers, and Volcano.
  - Noise/compound cases to test anchoring and partial diagnosis.
  - Checklist-style diagnosis evaluation dimensions: localization, characterization, and scope.
- From AIOpsLab:
  - Incident lifecycle framing: detection/localization/RCA/mitigation recommendation.
  - Agent-cloud interface with tools and observed feedback.
  - Per-case trajectory logging: input prompt, tool calls, output, time, and status.
